Script Loading: defer vs async

This page has three scripts in the <head>. The list shows the order they ran in.

Order the scripts ran

    What I learned

    • Normal script: stops the HTML from loading until it finishes, so the page appears later.
    • defer: downloads in the background and runs after the HTML is ready, in order. Best for main page scripts.
    • async: downloads in the background and runs as soon as it is ready, in any order. Best for independent scripts like analytics.
