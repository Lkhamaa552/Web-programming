Performance Test Page

This page was slow. I fixed it with the performance techniques from Week 9-2.

Scroll down to see more photos.

My fixes

  1. defer on the script, so it no longer blocks the HTML.
  2. width and height on every image, so the page does not jump while loading (no layout shift).
  3. loading="lazy" on images below the fold, so they load only when needed.
  4. fetchpriority="high" on the first image and preconnect to the image server, so the main image appears faster.
